# 013 — Сокращение системных инструкций

Сократить статический контекст ассистента, сохранив поведение генерации,
редактирования, просмотра каталога и итогового ответа.

## Реализация

Общие правила описываются один раз в `SYSTEM_PROMPT`: актуальный
`selected_sequence` важнее истории и summary, ссылки должны быть однозначными,
используются UUID вхождений, просмотр кандидатов не разрешает изменения,
одна успешная операция на запрос. `operation_already_started` запрещает
дальнейшие операции. Ограничение `Other/Starting` для replacement не запрещает
явный swap. Сохраняются примеры для выявленных ошибок модели: гипотетический
swap, неоднозначное местоимение, составная просьба и пустой итоговый ответ.

Описания tools содержат отдельные контракты: ID кандидатов из последнего поиска,
число новых элементов и UUID места вставки, явно выбранная первая асана.
Динамический system tail содержит актуальный snapshot, обязательную команду
Generate и два факта текущего запроса: `turn_operation_committed` и
`catalog_items_displayed`. Они берутся из state/runtime и сбрасываются при новом
запросе. Наличие выбранной секвенции само по себе не означает, что новый запрос
уже выполнен. Политика пустого ответа опирается на эти флаги, а общие инструкции
находятся в статическом начале. Версия cache prefix
автоматически меняется вместе с prompt, инструкциями и schemas.

`generate_sequence.count` теперь необязателен и принимает положительное целое
число без верхней границы либо `null`. Модель передаёт явное количество без
обрезания; для duration-only передаёт секунды и `count=null`. Python:

- отдаёт приоритет явному count и игнорирует одновременно переданную duration;
- при duration рассчитывает `max(1, floor(seconds / 40 + 0.5))`;
- без размера использует 9;
- ограничивает число элементов 45 и добавляет `generation.limit_applied=true`,
  `limit=45`, а для явного count — `requested_count`, только при ограничении.

В duration-режиме сообщение о лимите появляется только если выбранные позы
не покрыли бюджет времени. Если mirrored-позы укладывают запрошенную длительность
в менее чем 45 элементов, ограничение не объявляется применённым.

Сервис генерации по-прежнему учитывает 80 секунд на mirrored-позу, выбирает
случайный старт и проверяет позиции. Общий лимит операций, принадлежность UUID,
допустимость replacement и лимит добавления обеспечиваются существующим кодом.
Прогресс при явном count также ограничен 45. Обычный успешный результат сохраняет
прежний компактный JSON без дополнительного поля `generation`.

Основные файлы: [промпт](../../../src/langchain_app/services/assistant_agent.py),
[контекст](../../../src/langchain_app/services/sequence_context.py),
[tools](../../../src/langchain_app/tools/sequence.py),
[расчёт размера](../../../src/langchain_app/services/sequence_generator.py).

Подход сверён с [OpenAI Docs — Function calling](https://developers.openai.com/api/docs/guides/function-calling):
вычисления, известные приложению, выполняются кодом; описания tools также входят
в оплачиваемый входной контекст. Перенос текста между prompt и tools сам по себе
экономией не считается.

## Проверка

Offline-проверки используют настоящий agent/tool loop с fake model и проверяют
default, округление, приоритет count, ограничение генерации и метаданные лимита.
Отдельно проверяется передача обоих флагов после generation/display и их сброс
при следующем запросе с прежней выбранной секвенцией.
Полный набор покрывает выбранный старый вариант, `Other/Starting`, блокировку
повторных операций, ошибки/no_change, snapshot, кэш, UI и сохранение вариантов.

Live fixture переиспользует 16 swap- и 28 addition-сценариев и добавляет 11
проверок генерации, каталога и replacement. При явном live-запуске только выбранная GPT-модель вызывается по сети;
каталог, генератор и TypeSafe локальные. Это проверка выбора действий и текста,
качество реального подбора асан не оценивается. Provider retries и tracing отключены.

```bash
uv run python -m unittest discover -s tests -q
uv run --env-file .env python tests/fixtures/compact_instructions_dialogue.py \
  --model openai:gpt-6-luna --output /tmp/compact-instructions-dialogue.json
git diff --check
```

Сохранённые измерения 013 считались локально через `tiktoken.encoding_for_model("gpt-4.1")`:
prompt и инструкции отдельно, schemas — компактный JSON `convert_to_openai_tool`.
Сумма этих размеров не включает сообщения истории, snapshot и служебное
кодирование tools провайдером; она не равна reported input usage или стоимости.
