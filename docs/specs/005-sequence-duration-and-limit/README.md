# 005 — Длительность секвенции и обязательный лимит асан

При запросе по длительности обычная асана занимает 40 секунд, а зеркальная
(`bilateral=true`) — 80 секунд: по 40 секунд на каждую сторону. Зеркальная асана
остаётся одним элементом секвенции. Генератор учитывает фактически выбранные
асаны, включая первую, и завершает подбор при достижении бюджета времени.

Модель передаёт в `generate_sequence` длительность в `duration_seconds` и
предварительный `count = min(45, max(1, round_half_up(seconds / 40)))`.
Генератор сам вычисляет этот верхний предел и уменьшает фактическое количество
элементов с учётом зеркальных асан. Бюджет округляется до ближайших 40 секунд,
половины вверх. Всегда выбирается хотя бы одна асана; последняя зеркальная
асана может превысить округлённый бюджет на 40 секунд. Завершающие асаны
предпочтительны, когда они заполняют оставшийся бюджет или последний элемент.

Явное количество асан имеет приоритет над длительностью: модель оставляет
`duration_seconds=null`, и зеркальная асана считается одним элементом.
Без количества и длительности используется 9 элементов.

**Обязательное правило: секвенция содержит максимум 45 элементов.** Оно
действует для чата, Generate и Regenerate, включая запросы с большим явным
количеством и большой длительностью. Модель ограничивает `count` значением 45
и объясняет ограничение пользователю. Схема инструмента отвергает `count > 45`;
самостоятельный вызов генератора также отвергает такое значение до обращения
к каталогу. Инструмент также не выдаёт 46-й элемент и не сохраняет результат
подставленного генератора, нарушившего лимит. Этот лимит относится к генерации,
а не к импорту готовых секвенций.

Проверки: обычные и смешанные секвенции по длительности; зеркальная первая
асана; округление и короткий запрос; приоритет явного количества; граница
45 элементов и отклонение 46; передача длительности через реальный цикл tools.
