# 004 — Начальный элемент секвенции

Инструмент `generate_sequence` и сервис `SequenceGenerator.generate` принимают
необязательный `starting_catalog_item_id`. Если пользователь указывает первую
позу при генерации, ассистент находит её в каталоге или использует проверенный ID
из выбранной секвенции и передаёт генератору. При неоднозначном запросе ассистент
уточняет позу до генерации.

Переданный элемент имеет приоритет над случайным выбором и не обязан иметь тег
`Other/Starting`. Генератор проверяет, что ID есть в текущем каталоге и у элемента
есть миниатюра. Недоступный элемент вызывает ошибку без случайной подстановки.
Начальный элемент учитывается в `count` и исключается из последующих кандидатов.

Без явного ID генератор выбирает среди элементов с `Other/Starting` и миниатюрой:

| Положение | Теги | Вероятность |
| --- | --- | --- |
| Лёжа | `Position/Lying…` | 10% |
| Сидя | `Position/Sitting…`, включая сидя на коленях | 60% |
| Стоя | `Position/Standing` | 30% |

Сначала выбирается положение, затем случайная поза внутри него. Количество поз
в группе не влияет на вероятность положения. Если какая-то группа отсутствует,
веса оставшихся групп нормализуются. Если у всех стартовых поз нет этих тегов,
сохраняется равномерный случайный выбор среди стартовых поз.

Для второго элемента применяются правила независимо от способа выбора первого:

- После старта лёжа второй элемент должен иметь `Position/Lying on the back`.
- После старта стоя TypeSafe предпочитает `Position/Standing`; кандидаты с любым
  тегом `Position/Lying…` исключаются.
- После старта сидя дополнительных ограничений нет.

Фильтрация выполняется до выборки кандидатов и выбора финишной позы. Если второй
элемент одновременно последний, правило перехода имеет приоритет над
предпочтением `Other/Finishing`. Если подходящих кандидатов нет, генерация
завершается ошибкой, а незавершённая секвенция не сохраняется. Для `count=1`
правила второго элемента не применяются. TypeSafe также получает эти правила
в контексте выбора; ограничения не распространяются на третий и последующие
элементы.

Проверки: приоритет и валидация явного старта; распределение положений при разном
размере групп; отсутствие групп; ограничения второй позы, в том числе для
секвенций из двух элементов; передача правил TypeSafe; полный путь ассистента
«поиск → генерация с ID → сохранение секвенции» без внешних модельных вызовов.
